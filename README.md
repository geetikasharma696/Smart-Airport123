### Smart-Airport123 
# Smart Airport Management System

A Java and MySQL-based airport management application designed to manage
passengers, flights, check-ins, boarding passes, analytics and basic
AI-assisted airport operations.

## Project Objective

The objective of this project is to demonstrate how airport operations can
be managed through a centralized software system with database integration,
role-based access and intelligent analysis features.

## Main Features

- Admin login and airport management dashboard
- Passenger registration and management
- Flight creation and management
- Check-in management
- Boarding pass generation
- Passenger and flight data storage
- Basic AI-based passenger risk analysis
- Fraud detection module
- Flight delay prediction module
- Analytics dashboard
- Java Swing graphical user interface
- MySQL database integration

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- IntelliJ IDEA
- Git and GitHub

## Project Structure

- `ai` – AI analysis, risk and prediction modules
- `dao` – Database access classes
- `gui` – User interface screens
- `model` – Passenger and flight models
- `service` – Business logic
- `utils` – Database connection and boarding-pass utilities

## Database Setup

1. Install MySQL.
2. Create a database named `SmartAirport`.
3. Create the required passenger, flight, check-in and analysis tables.
4. Add your local database username and password in the database
   configuration.
5. Add MySQL Connector/J to the project libraries.

## How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Configure MySQL and JDBC.
4. Run the main application class.
